# AuthECAPI

ASP.NET Core Web API with Identity Authentication, Entity Framework Core, SQL Server, and Swagger UI.

## Packages

```bash
dotnet add package System.Security.Cryptography.Pkcs
dotnet add package Swashbuckle.AspNetCore
```

## Run Project

```bash
dotnet restore
dotnet run
```

## API Documentation

Open `/swagger` on your application's local URL to explore and test API endpoints in Development mode.

## Technologies

- ASP.NET Core
- ASP.NET Core Identity
- Entity Framework Core
- SQL Server
- Swagger UI
